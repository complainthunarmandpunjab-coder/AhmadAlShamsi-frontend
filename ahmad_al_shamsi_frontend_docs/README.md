# Ahmad Al Shamsi Real Estate — Frontend Design Documentation

This documentation defines the visual system, multi-page website structure, content rules, SEO foundations, motion behavior, and implementation standards for a premium international real-estate website inspired by the supplied reference screenshot.

## Design direction
- Editorial, premium, calm, and architectural — not a generic AI-generated landing page.
- Warm ivory surfaces, deep ink/navy text, restrained brushed-gold accents, real property photography, and generous whitespace.
- Multi-page information architecture with indexable URLs; do not build the entire website as one long single page.
- Use real icons from a consistent icon library or simple inline SVGs. Do not use emoji or decorative “AI-style” icons.
- Use Framer Motion sparingly for subtle transitions, entrances, and gallery interactions. Respect reduced-motion preferences.
